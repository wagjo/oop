# Výukové platformy

Na dnešnej hodine sa zaregistrujete na dvoch výukových platformách a vyskúšate si riešit jednoduché úlohy v Jave. URL na vaše profily mi zašlite cez Edupage.

## Edabit

Edabit ([https://edabit.com/](https://edabit.com/)) je interaktívna platforma na tréning programovania. Namiesto dlhých prednášok riešite krátke úlohy priamo v prehliadači: napíšete kód, platforma ho otestuje a hneď vidíte, či prešiel. Oficiálne sa zvykne prirovnávať k „Duolingu pre kódovanie“.

* Úlohy pre Javu nájdete na stránke [https://edabit.com/challenges/java](https://edabit.com/challenges/java)
* Úlohy pre Python nájdete na stránke [https://edabit.com/challenges/python3](https://edabit.com/challenges/python3)

!!! example "Úloha 1:"

    Zaregistrujte sa na stránke ([https://edabit.com/](https://edabit.com/))

    * Splňte aspoň 10 Java zadaní. Úlohy obtiažnosti *Very Easy* zvládnete aj s tým, čo sme doteraz preberali.
    * Pošlite mi cez EduPage URL na váš Edabit profil (môj profil je [https://edabit.com/user/SaNvxFq5kPWxQ4qJC](https://edabit.com/user/SaNvxFq5kPWxQ4qJC))


## CodinGame

CodinGame ([https://www.codingame.com/](https://www.codingame.com/)) je bezplatná herná platforma na tréning programovania: úlohy riešite priamo v prehliadači v Jave alebo Pythone (a ďalších 25+ jazykoch), pričom namiesto suchých testov často vidíte výsledok ako animáciu — robot, bludisko, preteky alebo súboj botov. Okrem klasických puzzle (Easy až Very Hard) sú tu rýchle súboje Clash of Code (kto prvý/najkratšie vyrieši krátky problém), dlhšie AI/bot súťaže a občas aj escape room.

Odporúčané úlohy pre začiatočníkov:

* [https://www.codingame.com/training/easy/onboarding](https://www.codingame.com/training/easy/onboarding)
* [https://www.codingame.com/training/easy/the-descent](https://www.codingame.com/training/easy/the-descent)
* [https://www.codingame.com/training/easy/temperatures](https://www.codingame.com/training/easy/temperatures)
* [https://www.codingame.com/training/easy/power-of-thor-episode-1](https://www.codingame.com/training/easy/power-of-thor-episode-1)
* [https://www.codingame.com/training/easy/mars-lander-episode-1](https://www.codingame.com/training/easy/mars-lander-episode-1)
* [https://www.codingame.com/training/easy/what-a-dessert](https://www.codingame.com/training/easy/what-a-dessert)
